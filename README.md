# controle_de_estoque

🧴 Perfumaria Artesanal - Controle de Estoque Inteligente
Este projeto nasceu de um desafio real: como transformar o controle de estoque manual (feito em cadernos e planilhas impressas) em uma ferramenta digital eficiente, sem perder a simplicidade e o conforto do método tradicional.

🎯 O Desafio
A cliente final possui domínio básico de computação, mas prefere a agilidade e o toque do papel. O objetivo aqui foi criar uma interface didática, funcional e livre de barreiras, focada em uma pessoa de mais idade que busca transicionar seu negócio para o digital.

✨ Diferenciais do Projeto
Design Humanizado: Interface baseada em elementos visuais conhecidos (estilo "fichário" e "caderno").

Foco em Acessibilidade: Botões amplos, fontes legíveis e alto contraste para facilitar a leitura.

Fluxo Simplificado: Redução da carga cognitiva, dividindo processos de entrada e saída de materiais em passos guiados.

Feedback Imediato: Confirmações visuais claras para cada ação realizada, garantindo segurança à usuária.

🛠️ Tecnologias Cogitadas/Utilizadas
UI/UX Design: Figma (Prototipagem de baixa e alta fidelidade).

Frontend: React.js / HTML5 / CSS3

Backend: JAVA SCRIPT

Banco de Dados: PHP
